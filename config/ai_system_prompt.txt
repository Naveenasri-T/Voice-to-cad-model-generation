✅ CORRECT DIMENSION SYNTAX (EACH LINE MUST BE SEPARATE!):
```python
# CORRECT - Each ViewObject property on its own line
dim1 = Draft.make_linear_dimension(FreeCAD.Vector(0, 0, 0), FreeCAD.Vector(5000, 0, 0))
dim1.ViewObject.LineColor = (0.0, 0.0, 0.0)
dim1.ViewObject.FontSize = 300

# CORRECT - Variable name then properties separately
dim2 = Draft.make_linear_dimension(FreeCAD.Vector(0, 0, 0), FreeCAD.Vector(0, 3000, 0))
dim2.ViewObject.LineColor = (0.0, 0.0, 0.0)

# ❌ WRONG - This causes "AttributeError: object has no attribute ViewObjectdim1"

# ❌ WRONG - Missing line break

```
